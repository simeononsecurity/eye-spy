Eye Spy

Surveillance Camera & Tracker Detector — ESP32 Web Flasher

Select Firmware

Requires Chrome / Edge on desktop. Connect ESP32 via USB.

Requirements

  • Chrome or Edge browser (desktop)
  • ESP32 connected via USB-C/USB-A cable
  • No extra drivers needed on modern OS
  • Approximately 1.5 MB free flash

Quick Start

  1. Select your board variant above
  2. Click Install and pick the COM/tty port
  3. Wait ~60 s for flash + verify
  4. Open Serial Monitor at 115200 baud
  5. Switch to Live Dashboard tab for real-time score + map

What It Detects

Eye Spy builds a cumulative suspicion score using BLE scan WiFi probe OUI fingerprint SSID heuristics MAC correlation to detect Axon body-cams, Flock Safety cameras, AirTags, drones, and other surveillance devices.

Serial format: [eyespy] +5 (Axon-cam) score=10 · [eyespy] status score=10 ALERT phase=BLE tracked=3
